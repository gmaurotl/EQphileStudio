# Security reports

Send potential vulnerabilities privately to **eqphile@maurotarazona.com**, with
the app version/build and a minimal reproduction. Avoid exposing other users'
information. Do not post exploitable details or secrets in a public issue.
This personal project offers no paid support SLA or bug-bounty commitment.

Support correspondence uses Microsoft Exchange Online; see [Privacy](PRIVACY.md).
The developer website is [maurotarazona.com](https://maurotarazona.com).

Download updates and their checksums from
[GitHub Releases](https://github.com/gmaurotl/EQphileStudio/releases).
Updates are installed manually. Checksums verify the download's integrity;
they do not replace Developer ID signing or Apple notarization.
